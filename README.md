# FocusFlow — Professional To-Do App

**Created by: Mahmudul Haq Rupom**

A polished, responsive task manager built with HTML5, CSS3 and vanilla JavaScript.

## Features
- Add tasks with due dates and priority (High / Medium / Low)
- Mark tasks complete or pending
- Edit and delete tasks
- Filter by All, Today, Pending and Completed
- Search tasks by title
- Sort by newest, oldest, priority or due date
- Task counters and completion progress bar
- Local Storage persistence after refresh
- Light and dark theme with saved preference
- Responsive desktop, tablet and mobile layout
- Safe rendering of task titles using DOM text nodes

## Folder structure
- `index.html` — application structure
- `css/style.css` — complete styling and responsive layout
- `js/script.js` — app logic and Local Storage
- `assets/` — reserved for future images/assets

## Run the project
1. Extract the ZIP.
2. Open the folder in VS Code.
3. Open `index.html` with Live Server, or open it directly in your browser.
4. Internet is needed for Google Fonts and Font Awesome icons.

## Personalize
Your name is already included in the sidebar, footer, page metadata and code comments as **Mahmudul Haq Rupom**. To change it, search for that text in `index.html` and replace it.

## Notes
This is a front-end portfolio project. Tasks are stored in the current browser only; there is no backend, login system or cross-device synchronization.
